쏟아지는 책,
내 취향은 어디에?
국내에서만 매년 약 70,000종의 신간이 출판됩니다. 정보의 홍수 속에서 '지금 나에게 맞는 책'을 찾는 것은 점점 더 어려운 일이 되고 있습니다.
연간 국내 신간 출판 약 70,000종
#1
베스트셀러만 보여주는
획일적인 추천
기존 플랫폼은 판매량·대출 순위 기반 추천에 그칩니다. 독자의 현재 감정, 읽고 싶은 분위기, 선호 문체 같은 개인의 맥락은 반영되지 않습니다.
성인 연평균 독서량 4.3권 (2024)
AI?
"이런 느낌의 책"을
말로 찾을 수 없었다
도서 검색은 키워드 입력에 의존합니다. 하지만 독자가 원하는 것은 대화처럼 자연스럽게 취향을 설명하고, 딱 맞는 책 한 권을 추천받는 경험입니다.
기존 서비스: 키워드 검색만 지원
One-line Value Proposition
AI 사서가 3~5번의 대화로 취향을 파악하고,
세상에서 가장 딱 맞는 책을 찾아드립니다
Riv는 단순한 도서 검색 앱이 아닙니다.
Google Gemini AI가 사서 역할을 맡아 대화를 통해 독자를 이해하고, 국립중앙도서관 실제 데이터 기반으로 구체적인 책을 추천합니다.

04
아키텍처 · 기술스택
Frontend
React Native + Expo
iOS · Android · Web을 단일 코드베이스로 지원. Expo SDK로 빠른 설정과 빌드. 1인 개발에 최적화된 크로스플랫폼.
Language
TypeScript
컴파일 타임 오류 검출로 런타임 안정성 확보. 타입 자동완성으로 스크린·API 인터페이스를 명확하게 정의.
AI
Google Gemini API
멀티턴 대화 + System Prompt 지원 → "AI 사서" 역할극 구현에 최적. 3단계 모델 Fallback(2.5-flash → flash-latest → 2.0-flash-lite)으로 안정성 확보.
Data
국립중앙도서관 Open API
국내 최대 도서 DB를 무료 제공. KDC 분류 검색 · 대출 인기 순위 지원. API 실패 시 Mock 데이터로 Fallback.
Storage
AsyncStorage
별도 백엔드 서버 없이 사용자 정보 · 독서 기록 · 캐시 잔액을 기기에 영구 저장. MVP 단계에서 인프라 비용 Zero.
State
React Navigation + ThemeContext
Stack + BottomTabs로 네이티브 수준 화면 전환. 커스텀 ThemeContext로 다크/라이트 모드를 전역 관리 · CSS 300ms 전환 애니메이션 적용.
